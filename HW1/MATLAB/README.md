# MATLAB Scripts

## Main calculation

`main.m` performs the MATLAB kinematic, static and dynamic calculations. It produces result tables, plots and `results_matlab/classroom_results.mat`. It does not use PMKS+ data.

## AI-written data analysis

`data_comparison_analysis.m` was written by AI (OpenAI Codex). Its role is limited to post-processing and data analysis:

- PMKS+ reference data were exported beforehand and hard-coded into the script.
- The script reads the MATLAB results generated by `main.m` and compares them with the embedded PMKS+ data.
- It calculates differences and produces comparison tables and plots in `results_pmks_comparison`.

The comparison script does not run PMKS+, connect to its website or independently solve the linkage equations. The embedded values are a fixed reference dataset, not a live simulation. If the model or simulation conditions change, matching PMKS+ data must be exported and the embedded dataset updated before using it for comparison.

Newton's second-law report results are MATLAB-only; they are not presented as a PMKS+ comparison.

## Run order

Run `main` first. Run `data_comparison_analysis` afterward only when comparison and data analysis are needed. `main` can run independently.
